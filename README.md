# 🧱 LEGO Master Builder Studio — v10.0

אפליקציית תכנון לגו מקצועית — קובץ HTML יחיד, ללא התקנות, מותאמת מובייל.

## מה היא עושה
- **20 ארכיטיפים ברמת מוצר**: פורמולה 1, מנוף נייד, מחפרון, מסוק, רכבת, משאית, אופנוע,
  ספינת פיראטים, טירנוזאורוס, דמות מפוסלת, בית, טירה, חללית ועוד — עם גלגלים עגולים,
  שיפועים, מפרשים וסכמות צבע אוצרות.
- **AI-אדריכל**: נושא שאין לו תבנית מורכב אוטומטית מספריית רכיבים פרמטריים (שלדות,
  זרועות טלסקופיות, רוטורים, תרנים...).
- **פסיפס LEGO Art מתמונה**: עיבוד תמונה מקומי מדויק — התאמת צבע פרספטואלית,
  Auto-Levels, Dithering נחשי, עד 30 צבעי לגו.
- **תצוגה תלת-ממדית** (WebGL): צללים רכים, מצב הרכבה שלב-אחר-שלב עם הדגשות.
- **רשימת חלקים (BOM)** עם מק"טי BrickLink אמיתיים — מקור אמת יחיד למספר החלקים.
- **הזמנות מוכנות**: BrickLink Wanted List XML · BrickOwl CSV · LEGO Pick a Brick.
- **ייצוא ל-BrickLink Studio** (.ldr) — רנדר מלא + חוברת הוראות הרכבה.
- **אריזת לגו 🎁** — קופסה שיווקית 2400×1800 מהדגם שלך.
