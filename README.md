# קדם · Kedem

אפליקציית PWA דו-לשונית (עברית ואנגלית) לסיפורי התנ"ך: לכל סיפור סרטון אנימציה, הסבר בלוחות מאוירים, הפסוקים במקור, שכבות פרשנות (פשט, דרש, סוד), דמויות ושאלות.

## הרצה

אין שלב בנייה. מגישים את התיקייה כאתר סטטי:

```
python3 -m http.server 8000
```

ופותחים את `http://localhost:8000`. אפשר לכפות שפה עם `?lang=he` או `?lang=en`.

## קבצים

- `index.html`, `css/app.css` — המעטפת ומערכת העיצוב "היכל"
- `js/app.js` — בית, מפת הספרים, "אני" ומסך הסיפור
- `js/i18n.js` — מחרוזות הממשק בשתי השפות וכיוון הכתיבה
- `content/index.js` — הספרים, המשלבים, הסיפורים והסיפורים שבהפקה
- `content/<id>.js` — סיפור אחד; כל שדה טקסט הוא `{ he, en }`
- `scenes/kit.js` — ערכת האיור (דמויות, שמיים, מסגרת, תוויות); `scenes/<id>.js` — הלוחות של הסיפור
- `scenes/preview.html?id=<id>&lang=he` — תצוגה של כל הלוחות של סיפור
- `sw.js` — עבודה בלי רשת; מעלים את מספר המטמון בכל שינוי
- `fonts/` — Heebo ו-Frank Ruhl Libre (רישיון OFL, מצורף)

## מצב

פיילוט: סיפור אחד (דוד וגוליית, שמואל א י"ז). הסרטון, החיבור לאפליקציית הניהול והסיפורים הבאים עדיין לא נבנו.
הפסוקים בעברית נכתבו מהזיכרון וצריכים הגהה מול נוסח מוסמך; התרגום לאנגלית לפי JPS 1917.
